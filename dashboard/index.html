TOKEN RADAR v2

Every pre-token protocol in the snapshot, ranked by what its token would be worth if it launched at the size the live market already pays for. Implied values are this entry's own claim, not a prediction that a token launches.

How the model was tested

Implied value = fitted size curve on live-token comparables, times a 7-day growth factor (clamped 0.8–1.2), times an age factor (0.85–1.00, older unlaunched protocols score lower). Curve: log10(mcap) = a + b·log10(TVL), fitted per category when it has ≥5 live comps, otherwise shrunk to the global fit. Capped at 10× TVL.
